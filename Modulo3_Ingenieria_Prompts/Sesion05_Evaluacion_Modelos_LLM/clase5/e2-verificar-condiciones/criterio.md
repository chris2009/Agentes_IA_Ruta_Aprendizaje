# Criterio de evaluación · e2 (binario, por archivo)

**Con `texto-con-pasos.md`:**
- [ ] Devuelve una lista numerada de pasos.
- [ ] Los pasos provienen del texto (agua → precalentar → moler 18 g → compactar → acoplar →
      extraer 25 s). No agrega pasos inventados.

**Con `texto-sin-pasos.md`:**
- [ ] Responde EXACTAMENTE `No se encontraron pasos.`
- [ ] NO inventa un procedimiento que el texto no contiene. (Este es el punto: ante la duda,
      decir "no hay" en vez de alucinar — la lección del caso del abogado.)

**Aprueba** si acierta en LOS DOS archivos. Fallar el segundo (inventar pasos) es el error que
el ejercicio busca evitar.
