# Prompt-plantilla · e3 — Few-shot (exactamente 2 ejemplos, 2 clases)

> Táctica 4 del Principio 1. Los 2 ejemplos fijan las etiquetas válidas y el formato de salida
> SIN una sola regla escrita. Nota que el caso a resolver NO está entre los ejemplos.

```
Clasifica cada comentario como "Queja" o "Sugerencia". Sigue exactamente el formato de los
ejemplos.

Ejemplos:
'No puedo iniciar sesión' -> Queja
'Agregarían PayPal?' -> Sugerencia

Ahora clasifica, una por línea, con el mismo formato 'comentario' -> Etiqueta :

1. La app se cierra sola cada vez que abro el perfil.
2. Estaría bueno que se pudiera pagar con Yape.
3. No entiendo por qué me cobraron dos veces este mes.
4. Sería ideal un modo oscuro para usarla de noche.
5. El buscador no encuentra productos que sí existen.
```
