# Input · tarea (el caso nuevo a resolver)

Pega este caso al final de `prompt-plantilla.md`, donde dice `{...}`. **No** está entre los
ejemplos: es el caso que el modelo debe resolver imitando el patrón de los 2 exemplars.

---

Una fábrica tiene **6 máquinas idénticas**. Cada máquina produce a la **misma tasa por hora** que
en los ejemplos anteriores. ¿Cuántas **horas** se necesitan para fabricar **180 piezas** usando las
6 máquinas a la vez?
