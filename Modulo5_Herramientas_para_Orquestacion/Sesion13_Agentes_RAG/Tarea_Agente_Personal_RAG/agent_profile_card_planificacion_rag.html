Agentic System Profile Card

Agente Personal de Planificación Académica (con RAG)

Prioriza tareas académicas pendientes según fecha límite y prioridad, distribuye el tiempo disponible entre ellas, y responde preguntas sobre los documentos asociados a cada una mediante búsqueda semántica real (RAG con Chroma), con búsqueda web como respaldo.

Goal-Based Agent

Communication Layer

Conversacional

Canal: consola / chat de texto (uso personal, un solo usuario). Cada respuesta se entrega en formato estructurado (resumen, acciones recomendadas, fuentes citadas, herramientas usadas), no como texto libre.

Context Definition

Domain Definition

Dominio: Gestión de tareas académicas pendientes (prioridad, fechas límite, estado) y respuesta a preguntas sobre los documentos asociados a cada una, mediante recuperación semántica (RAG).

Alcance: Registrar, consultar y actualizar tareas; calcular su urgencia; distribuir el tiempo disponible entre ellas; indexar los documentos de materiales/ en una base vectorial (Chroma) y responder preguntas de contenido aunque no usen las palabras exactas del documento; complementar con búsqueda web cuando los materiales locales no alcanzan.

Restricción clave: No accede a ninguna ruta fuera de la carpeta autorizada, no ejecuta archivos, no integra Google Calendar en esta versión.

Objectives Definition

  • Consultar y priorizar tareas pendientes según fecha límite y prioridad declarada.
  • Distribuir las tareas dentro de un bloque de tiempo disponible.
  • Indexar y buscar semánticamente (RAG) dentro de los documentos de una tarea, con citación de fuente.
  • Usar búsqueda web (Tavily) como respaldo cuando el RAG local no encuentra información relevante.
  • Actualizar el estado de una tarea conforme el usuario avanza.

Environment Definition

Knowledge

  • Tareas registradas en tareas.json: fecha límite, prioridad, duración estimada, estado.
  • Documentos de materiales/ (PDF, DOCX, TXT, Markdown, Python), divididos en fragmentos (chunking con solape) e indexados como embeddings en una colección Chroma persistente (chroma_index/).
  • Embeddings generados con Ollama local (nomic-embed-text) — sin depender de una API de pago.
  • Resultados de búsqueda web (Tavily) cuando se usan, no persistidos entre sesiones.

Tools

  • consultar_tareas / agregar_tarea / actualizar_estado — gestión del archivo de tareas.
  • calcular_prioridad / generar_plan — urgencia y distribución del tiempo.
  • guardar_plan_detallado — guarda un plan de texto libre ya redactado en el chat.
  • inspeccionar_carpeta — lista los documentos disponibles de una tarea.
  • buscar_en_documentos — RAG real: búsqueda semántica con Chroma, opcionalmente filtrada por tarea.
  • buscar_en_la_web — búsqueda web (Tavily) de respaldo.

Short Term Memory

Historial de mensajes de la sesión activa (incluye llamadas a herramientas), reutilizado en cada turno para mantener contexto conversacional.

Long Term Memory

tareas.json persiste el estado de las tareas entre sesiones. El índice vectorial en chroma_index/ persiste el conocimiento indexado de materiales/ en disco, sin necesidad de reconstruirlo en cada arranque.

Autonomy Dimension Definition

Semi-autónomo

Decide por su cuenta el orden de prioridad, el plan de tiempo, y cuándo usar búsqueda semántica local vs. búsqueda web, sin pedir confirmación para esas lecturas.

Limitaciones: no modifica ni crea eventos de calendario externo, no marca una tarea como completada por su cuenta — requiere que el usuario lo confirme vía actualizar_estado — y no accede ni escribe fuera de tareas.json y la carpeta autorizada.

Criticality Dimension Definition

Nivel de criticidad: Bajo-medio (uso personal, sin impacto en terceros)

Risk

  • Cálculo de prioridad incorrecto por una fecha o prioridad mal ingresada.
  • Pérdida o corrupción de tareas.json por escritura concurrente.
  • Recuperación semántica imprecisa: un chunk recuperado puede ser relevante por similitud pero no responder realmente la pregunta (limitación inherente a RAG, no solo de esta implementación).
  • Índice desactualizado si se agregan documentos a materiales/ sin correr --reindexar.
  • Una ruta fuera de la carpeta autorizada aceptada por error de validación.

Reglas de Operación + Guardrails

REGLACualquier ruta fuera de la carpeta autorizada se rechaza antes de leer nada.

REGLASolo se procesan extensiones de la lista blanca (PDF, DOCX, TXT, MD, PY); ningún archivo se ejecuta.

REGLAToda respuesta debe citar en fuentes los archivos o resultados web efectivamente consultados — el agente nunca inventa contenido de un documento no recuperado.

REGLAactualizar_estado requiere confirmación explícita del usuario, nunca se marca automáticamente.

REGLAbuscar_en_la_web solo se usa como respaldo cuando el RAG local no alcanza, nunca como primera opción.
