# LangGraph - Workflows, Agent y MultiAgents

Introducción y ejemplos de uso de **LangGraph**, una librería para construir aplicaciones con flujos de trabajo basados en grafos utilizando modelos de lenguaje.

## 📋 Contenidos del Repositorio

```
Modulo6/
├── intro.ipynb          # Introducción a LangGraph
├── mas.ipynb            # Ejemplos adicionales y casos de uso avanzados
├── requirements.txt     # Dependencias del proyecto
├── lab/                 # Ejercicios prácticos para resolver
├── sol/                 # Soluciones a los ejercicios
└── README.md            # Este archivo
```

## 🚀 Inicio Rápido

### Requisitos Previos

- Python 3.8+
- pip (gestor de paquetes de Python)
- Conocimientos básicos de Python

### Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/alzamoralabs/Modulo6.git
   cd Modulo6
   ```

2. **Crear un entorno virtual (recomendado):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # En Windows: venv\Scripts\activate
   ```

3. **Instalar las dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Iniciar Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```

## 💡 Conceptos Clave de LangGraph

LangGraph permite crear:
- **Grafos de flujo de trabajo**: Define el flujo lógico de tu aplicación
- **Nodos y aristas**: Componentes básicos del grafo
- **Integración con IA**: Conecta modelos de lenguaje a tus grafos
- **Manejo de estado**: Gestiona el estado a través del grafo
- **Validación y control**: Implementa lógica condicional
